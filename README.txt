موقع دعوة عروسة — نسخة ثابتة لرفعها على GitHub Pages

محتويات الملف (كل الملفات في مستوى واحد بدون مجلدات):
- index.html: الصفحة الرئيسية
- samples.html: صفحة نماذج الدعوات التسعة
- style.css: التصميم المتجاوب للموبايل والكمبيوتر
- script.js: الفلاتر وتفعيل الروابط
- config.js: روابط التواصل ونماذج Google التي ستُضاف لاحقًا
- invite-01 إلى invite-09: صور الدعوات الأصلية، بما فيها حنة Soha (08) وسبوع Reem (09)

طريقة الرفع من الموبايل:
1) افتحي مستودع GitHub: hendmostafarasheed/da3wet-3arousa-website
2) اختاري Add file ثم Upload files.
3) فكّي ضغط ZIP على جهازك أولًا. ارفعي كل الملفات الموجودة داخله معًا إلى جذر المستودع (الصفحة الرئيسية للمستودع)، وليس داخل مجلد.
4) لو ظهرت ملفات بنفس الأسماء، اختاري استبدالها/ارفعي النسخ الجديدة.
5) اضغطي Commit changes.
6) من Settings > Pages تأكدي أن النشر من الفرع main ومن المجلد /(root)، ثم انتظري اكتمال النشر.
7) افتحي: https://hendmostafarasheed.github.io/da3wet-3arousa-website/

ترتيب الملفات لا يهم بعد رفعها؛ المهم أن تكون index.html وsamples.html وstyle.css وscript.js وconfig.js والصور كلها في الجذر نفسه. لا ترفعي ملف ZIP نفسه بدل محتوياته.
